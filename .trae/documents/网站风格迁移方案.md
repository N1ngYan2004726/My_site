# 网站风格迁移方案：模仿 leslie-lu.github.io 学术风格

## Context（背景）

用户希望将其 Quarto 学习笔记网站（e:\My_site）的视觉风格全面迁移为模仿目标网站 https://leslie-lu.github.io/ 的学术风格设计，同时保留现有内容（4个板块的学习笔记）。

**目标网站设计特征**（Hugo Academic / Quarto 学术个人主页风格）：
- 字体：Inter（无衬线）+ Fira Code（等宽）
- 配色：浅灰背景 #f8f9fa、品牌海军蓝 #003f87、Bootstrap 灰色系
- 布局：居中 860px、大量留白、简洁卡片、最小化边框
- 首页：头像 + 个人简介网格布局（非巨型 Hero）
- 博客页：按年份分组的文章列表
- 代码块：GitHub Light 风格（浅色背景）

**当前网站特征**：
- Quarto cosmo 主题 + 自定义 CSS（~1384 行）
- 暖米色背景、4 个板块各自配色（蓝/青/橙/紫）
- 首页有巨型 Hero（5.6rem 标题）+ 卡片网格
- 深色模式支持 + localStorage 分类系统

## 迁移策略

**视觉风格 ~85% 还原，功能 100% 保留**：
- 采纳目标站的字体、配色、排版、卡片极简风格、年份分组列表
- 保留当前站的 4 板块信息架构、分类系统、深色模式、CSS 变量主题机制

## 关键约束（必须遵守）

1. **分类系统不可破坏**：[category-enhancer.html](file:///e:/My_site/assets/category-enhancer.html) 依赖以下选择器，CSS 重写时必须保留：
   - `.quarto-listing`, `.quarto-post`, `.listing-title a`
   - `.quarto-listing-category`, `.category`, `[data-category]`, `.quarto-category-count`
   - `.page-category-selector`, `.category-input`, `.submit-category`, `.cat-tag`
   - `.listing-no-matching`, `.d-none`

2. **保留 `type: default` 列表类型**：不切换到 `template: blog`，否则分类 JS 会失效

3. **深色模式 WCAG 合规**：所有文字对比度 ≥ 4.5:1

4. **内容居中**：`--max: 860px` + `margin: 0 auto` 保持不变

5. **主题切换功能保留**：[theme-toggle.html](file:///e:/My_site/assets/theme-toggle.html) 和 [theme-switch.js](file:///e:/My_site/assets/theme-switch.js) 不需修改

## 风险与缓解

| 风险 | 缓解措施 |
|---|---|
| `group-by` 语法版本不兼容 | 检查 Quarto 版本，备选 `grouping: date` 或手动年份标题 |
| Google Fonts 网络加载失败 | 字体回退链已包含 system-ui |
| 分类 JS 选择器被误改 | 实施后 grep 验证所有选择器存在 |
| 深色模式对比度不足 | 使用 WebAIM 对比度检查器验证 |
| 头像资源缺失 | 使用首字母占位符或省略头像列 |
